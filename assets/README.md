# Иконка лаунчера

Кладёте сюда `icon.ico` — и он становится иконкой окна, панели задач и exe.
Файл необязательный: если его нет, лаунчер рисует иконку сам
(скруглённый квадрат с кубиком в цвете темы) — `launcher/appicon.py`.

| Файл | Где используется | Требования |
| --- | --- | --- |
| `icon.ico` | окно, панель задач, `.exe` (PyInstaller) | 256×256, квадрат, без мелких надписей |
| `icon.png` | украшение экрана загрузки | можно 512×512, с надписью |

Приоритет: `icon.ico` из папки установки → `icon.ico` из ресурсов сборки →
сгенерированная иконка. Баннер `icon.png` в иконку окна не попадает намеренно:
мелкий текст при уменьшении превращается в кашу.

Сгенерировать `icon.ico` из своей картинки:

```bash
python -c "from pathlib import Path; from launcher.appicon import export_ico; \
print(export_ico(Path('icon.ico')))"
```
